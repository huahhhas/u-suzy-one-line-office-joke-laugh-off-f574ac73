# One-Line Office Joke Laugh-Off

One original one-line joke about office life, written to get the biggest laugh out of coworkers:

> The office fridge says 'label your food,' so I labeled mine 'evidence' — nobody's touched it since.

The twist lands in the last few words: a petty fridge-label rule meets a word that makes everyone suddenly respect your leftovers.

`main.py` (pure Python stdlib) writes the single line to `/output/entry.txt`, validated to the gate: 1–200 characters, not only whitespace, one line.
